## 2. 模擬国連の設計方針

### 2.1 議題の範囲

本会議は史実の優先テーマ（論点①：経済×女性）とフォーカスエリア（論点③：先住民族×女性）を統合した合意結論のコンセンサス採択をゴールとする。

残る史実上の主要争点は以下の5点であり、十分な交渉密度を持つ：

| 争点 | 対立軸 |
|------|--------|
| A：SRHR「権利」表現 | 革新派 vs OIC保守派 |
| B：開発の権利・ODA義務 | G77 vs 先進国 |
| C：先住民族の権利宣言の援用強度 | 革新派 vs 米国・カナダ |
| D：「政策空間」文言の実質条項への波及 | 保守派 vs 革新派 |
| E：CEDAW留保の「撤回」vs「見直し」 | 革新派 vs 包括留保国 |

### 2.2 会議コンセプト

> **「CSW59の失敗を参加者自身が対話で乗り越える体験」**

単なる文言のバーター交渉ではなく、以下の3点を会議設計の核心に置く：

1. **各陣営の理念的止揚**：「内政不干渉だからムリ」というワンパターンの攻防を超え、各ブロックの内部矛盾を露呈させることで理念的な対話を生む
2. **CSW59の失敗の克服体験**：「人権」という抽象語の正面衝突ではなく、既存文書の文言を援用した迂回表現の発明という**法的創造性の競争**として設計する
3. **高いハードルのコンセンサス採択**：全員が「不満だが受け入れられる」ギリギリの文言に着地することを明るい目標として設定しつつ、到達が容易ではない構造にする

## 3. 会議テーマの前提に埋め込まれた深層的緊張

### 3.1 「変化する労働の世界」という前提の解剖

本会議のテーマ設定には以下の世界観が暗黙に埋め込まれています：

- グローバル化した市場経済が存在する
- 技術革新（デジタル化・自動化）が労働市場を変容させている
- その変容の中で女性が平等に参加できるようにする

合意結論第23段落がこれを明示している：「グローバリゼーションが女性の経済的エンパワーメントに機会と課題の両方をもたらすことを認識する」。グローバリゼーション自体の是非は問わない。所与の条件として受け入れた上で女性の地位向上を論じる構造です。

### 3.2 発展の権利との構造的緊張

**発展の権利（Right to Development）の本来の射程：**

発展の権利宣言（1986年・総会決議41/128）は脱植民地化後の新国際経済秩序（NIEO）要求の延長として設計されました。各人民が自らの発展モデルを選択する権利、資源に対する永久主権が中核です。本来は「共通化への抵抗」の道具として機能するはずでした。

**CSW61での発展の権利の援用形態：**

合意結論第10段落に「開発の権利を含む、すべての女性・女児の人権と基本的自由」という表現が挿入されています。G77がこの挿入を要求したのは、ODA義務要求を「人権義務の履行」として位置づけるためです。

ここに根本的な変質があります：

```
本来の発展の権利（1986年）：
「我々は異なる発展モデルを選ぶ権利がある」
「共通化への抵抗」
　　↓ 歴史的変容（冷戦終結・グローバル化）
CSW61での発展の権利（2017年）：
「グローバル市場への参加は所与」
「参加コストを先進国が払え」
「共通化への参加費用の要求」
```

G77はグローバル市場経済への統合を選択・あるいは余儀なくされた結果、発展の権利を「共通化への抵抗」ではなく「共通化への参加費用の要求」として使うようになっています。

**「誰の発展か」問題：**

発展の権利宣言第1条は「人民（peoples）」を権利主体の一つとしており、国家が発展の権利を代表して行使する余地があります。しかし「変化する労働の世界における女性の経済的エンパワーメント」は女性**個人**を権利主体とします：

```
発展の権利の国家代表論：
「我が国の発展の在り方は我が国が決める」
「女性の経済参加の形も国家・文化的文脈の中で決まる」
        ↕ 抵触
女性の経済的エンパワーメント論：
「女性個人が経済的権利の主体」
「国家・家族・文化が個人としての女性の権利を制限してはならない」
```

**技術移転の非対称性：**

合意結論第25段落の「相互合意した条件での技術移転」要求は、「変化する労働の世界」を作り出した先進国の技術に途上国が適応するための費用を先進国に求める構造になっています。発展の権利が想定した「自律的発展」ではなく、先進国が生み出した変化への対応コストの分担要求です。

**「ディーセントワーク」概念の普遍性問題：**

合意結論全体を通じてILOの「ディーセントワーク」概念が基準として使われていますが、これは有償・個人・正規雇用を中心とする西側の労働観を前提としています。共同体的・互酬的・非貨幣的な経済活動は「ディーセントワーク」の枠外に置かれ、正規有償雇用への転換の対象として位置づけられます（合意結論第40条(nn)）。これはグローバル市場経済への包摂を「発展」として自明視した設計です。

### 3.3 深層的逆説

これらを統合すると、最も根本的な問いが浮かび上がります：

> **「変化する労働の世界における女性の経済的エンパワーメント」というテーマ自体が、発展の権利が保障しようとした「自律的な発展モデルの選択」を、特定の経済モデル（グローバル市場経済）への包摂として書き換えていないか？**

さらに深刻なのは、発展の権利を援用することでグローバル市場経済への女性の参加が加速し、発展の権利が本来守ろうとした多様な発展モデルが侵食されるという逆説です。

この深層的緊張は会議中に参加者が自力で到達することは難しいが、**転換点①の交渉が最も深いレベルで機能したとき**に表面化します。

## 4. 交渉ダイナミクスの設計：4局面と3つの転換点

### 4.1 4局面の構成

```
局面①：序盤（前文交渉）
  ↓ 転換点①：保守ブロック内部分裂の誘発
局面②：中盤（実質条項・3つの同時進行する攻防）
  ↓ 転換点②：先住民族論点で保守派の論理が自己矛盾する
局面③：後半（SRHR迂回表現の発明）
  ↓ 転換点③：CSW59方式（正面衝突）からCSW61方式（迂回）への転換
局面④：終盤（政策空間条項をめぐる最終攻防→コンセンサス採択）
```

---

### 4.2 局面① 序盤：前文交渉

**最初の攻防点：PP5（ICPD「再確認」か「想起」か）**

革新派がカイロ行動計画（ICPD）を「再確認（reaffirm）」する文言を要求。サウジ・バチカンが「想起（recall）」へのダウングレードを要求。この一語の差がSRHR攻防の伏線となるため、革新派の最初の「死守ライン」として機能する。

**PP6「政策空間」の前文への挿入**

ロシア・中国が「各国の政策空間とリーダーシップを尊重」という文言の挿入を要求。革新派はこれが後の実質条項の抜け穴になることを察知し抵抗するが、「前文に限定する」という条件で受け入れる方向へ。

**PP7のパッケージ交渉**

「普遍的・不可分・相互依存」（革新派の要求）と「開発の権利を含む」（G77の要求）を同一段落に共存させるパッケージ交渉が発生。双方が片方ずつ不満を抱えながら受け入れる構造。

---

### 4.3 転換点①：保守ブロック内部分裂の誘発

**設計上の仕掛け：G77資金要求を先行させる**

実質条項のB（開発の権利・ODA）の交渉を先行させることで、OIC保守国（サウジ・インドネシア）がG77として先進国に資金要求を突きつける側に回る局面を作る。

**露呈する矛盾：**

「内政不干渉」を盾に人権表現を拒否していた国が、今度は先進国に資金コミットメントを求める。革新派（北欧・EU）がこの非対称性を突く：

> 「あなた方は開発には外部コミットメントを求め、人権には内政不干渉を主張する。この非対称性をどう正当化するか？」

**深層的な問いへの展開（理想的な場合）：**

この攻防が深まると、発展の権利の変質という問いに接続します：

```
革新派：「あなた方が要求しているのは、グローバル化した
　　　　 システムへの参加コストの補填であり、そのシステム
　　　　 自体への批判ではない。発展の権利が本来意味した
　　　　 『自律的な発展モデルの選択』はどこに行ったのか？」

G77（サウジ）：「開発の権利は既確立の国際法原則。人権の
　　　　　　　　普遍性は西洋的価値の押しつけ」

中国：「開発の権利こそが最も基本的な人権。
　　　　グローバル化の恩恵を享受している先進国が
　　　　費用を負担するのは当然」

革新派：「しかしそのグローバル化したシステムへの参加を
　　　　 所与としている時点で、発展モデルの選択権は
　　　　 すでに放棄されていないか？」
```

**先進国が「支援しますわ」で終わらないための設計：**

先進国代表団が安易に資金支援を約束することを防ぐ構造として、G77が「支援の意思があるなら義務化の文言に同意を」と畳み掛け、先進国が「支援の意思はあるがSRHR推進を条件とする」と返す局面を設計に組み込む。

するとOICが「条件付き支援は内政干渉であり発展の権利の侵害」と論じざるを得なくなる。「支援の意思」と「条件の受け入れ可否」が分離し、G77内部の亀裂（条件付きでも支援を取る南アフリカ・ブラジル vs 条件なしを要求するサウジ・インドネシア）が可視化される。

---

### 4.4 局面② 中盤：3つの同時進行する攻防

**攻防A：CEDAW留保（(a)条項）**

```
革新派：「留保を撤回する（withdraw）」
　　↕
サウジ・インドネシア：「留保は主権的権利。撤回要求は内政干渉」
　　↕
最終調停候補：「撤回することを検討し見直す（review with a view to withdrawing）」
```

**攻防B：ODA・技術移転（(ll)(ee)条項）**

```
G77（南アフリカ・インド）：「ODA義務を履行する（fulfill the obligation）」
　　↕
EU・北欧：「促す（urge）にとどめる。義務化は拒否」
　　↕
米国（トランプ政権）：「0.7%目標の文言自体を削除」を要求
　　↕
G77の結束強化：米国の削除要求がG77を結束させてODA義務論をエスカレートさせる（バックファイア）
　　↕
最終調停候補：「促す（urge）」＋0.7%目標値は残存
```

なお「技術移転」をめぐる争点には3.2で論じた深層的非対称性が潜んでいる。「変化する労働の世界」を作り出した先進国の技術に途上国が適応するための費用を先進国に求める構造であり、発展の権利が本来想定した「自律的発展」とは異なる。

**攻防C：先住民族の権利宣言（(gg)条項）**

```
革新派・ブラジル：先住民族の権利宣言を「再確認する（reaffirm）」
　　↕
米国・カナダ：宣言への反対・棄権国として「重要性に留意する（noting the importance of）」へのダウングレードを要求
　　↕
サウジ・インドネシア：「伝統的・先祖代々の文化慣行を尊重する」という文言の挿入を試みる
```

---

### 4.5 転換点②：先住民族論点で保守派の論理が自己矛盾する

**設計上の仕掛け：「文化的固有性の尊重」の逆用**

「文化慣行を尊重する」という保守派が挿入しようとした表現を、革新派が逆用する：

> 「インドネシアやインドは国内に先住民族・少数民族を抱えている。『先住民族女性の伝統的慣行を尊重せよ』という表現は、自国の少数民族コミュニティへの外部批判を封じる根拠にもなるが、同時に自国の少数民族女性への差別的慣行（花嫁代償・女性割礼等）を温存することも意味しないか？」

**保守ブロックの分裂：**
- サウジ：先住民族問題と無縁なので「文化慣行の尊重」に賛成できる
- インドネシア・インド：自国の少数民族政策への批判に転化しうるため留保が必要になる

これで「保守 vs 革新」という二項対立が崩れ、保守ブロック内部の利害分裂が可視化される。

---

### 4.6 局面③ 後半：SRHR迂回表現の発明（クライマックス）

**CSW59の失敗パターン（再現してはいけない）：**
「人権」表現をめぐる抽象的正面衝突 → 保守ブロックの全面削除要求 → 着地点を失って政治宣言に格下げ

**CSW61方式（参加者に発見させる）：**
「SRHR」という一語を回避しつつ、カイロ行動計画（PP5で「再確認」済み）の文言を援用することで実質を確保する迂回表現の発明。

```
革新派の要求：「性と生殖の健康と権利（SRHR）」の一語明記
　　↕
保守派の要求：「権利」を「健康」に変えよ
　　↕
北欧が提案する迂回表現：
「国際人口開発会議行動計画および北京行動綱領に従い、
 女性の人権には、強制・差別・暴力なしに性的・生殖的健康を含む
 事項を自ら制御・決定する権利が含まれることを認識する」
```

保守派が受け入れ可能な論理：カイロ行動計画はPP5で「再確認」されている。その内容の反復に過ぎないという論理で拒否しにくい。

革新派が不満を抱えつつ受け入れる論理：「制御・決定する権利」という実質的な権利表現が残っている。

これがCSW59克服の瞬間：抽象語の正面衝突ではなく、すでに合意済みの過去文書の文言を積み重ねることで実質を確保する——これがCSW交渉の本質的な技術。

---

### 4.7 局面④ 終盤：政策空間条項をめぐる最終攻防

ロシア・中国が実質条項の末尾に以下の条項の挿入を要求：

> 「上記の行動要請の実施は、国内法および各国の優先事項、ならびに異なる国家・地域の慣行・アプローチを十分に考慮しながら行われるものとする」

この要求の根拠は2030アジェンダ（全加盟国が賛成）から引用された「政策空間」概念であり、革新派は概念そのものを否定できない。

革新派の反論：「前文PP6にすでに政策空間への言及がある。実質条項への挿入はすべての行動要請を事実上無効化する白紙委任条項だ」

議長（ブラジル）の調停：「PP6への政策空間言及で十分。実質条項への挿入は受け入れられない。ただし各条項の冒頭に『適切な場合には（where appropriate）』という限定句を追加することで、各国の状況への配慮を示す」

この政策空間攻防は3.2の深層的緊張と直接接続している。「各国の発展モデルを尊重する」という政策空間論は、グローバル市場経済への包摂を自明視した会議テーマへの保守派からの根本的異議申し立てとも読める。

## 5. 代表団設計

### 5.1 代表団一覧と交渉上の役割

| 代表団 | ブロック | 主要な戦略目標 | 固有の制約・矛盾 |
|--------|---------|--------------|----------------|
| EU | 革新派 | SRHR実質確保・CEDAW留保撤回要求 | トランプ政権の動向を警戒し守勢に回る |
| 北欧（スウェーデン・ノルウェー） | 革新派 | SRHR迂回表現の発明・jus cogens接続論 | ODA 0.7%目標は自国達成済みで比較的柔軟 |
| ロシア | 保守派 | 「人権」表現の希釈・政策空間条項の実質条項挿入 | CEDAW留保なし批准→「義務不履行では？」と突かれる |
| サウジアラビア | OIC保守派 | SRHR「権利」表現の阻止・ICPD「再確認」のダウングレード | CEDAW包括留保→革新派に無効論を突きつけられる |

### 参加者に体感させるべき3つのこと

**① 文言は政治である**
「再確認（reaffirm）」と「留意（note）」の違い、「権利（rights）」と「健康（health）」の違い——一語の差に各国の利害と長期的な規範形成戦略が凝縮されている。

**② ソフトローは「積み重ね」で意味を持つ**
合意結論は法的義務を生まないが、「前回の合意結論を再確認する」という文言の積み重ねがopinio jurisを形成し、将来のハードロー化への布石となる。

**③ ロジックの応酬は「武器の交換」ではなく「矛盾の発見」で動く**
「内政不干渉だからムリ」というワンパターンは、その国自身の他の主張との矛盾を突かれたとき初めて動く。特に発展の権利の援用が「共通化への抵抗」か「参加費用の要求」かという問いは、その矛盾を最も鋭く照らし出す。
