# HTMLレビューワークフロー（reviewable-html-workbench）

Claude のリサーチ成果物を、チャットではなく **HTML上のインラインコメント** でレビューする手順です。

## いまレビューできるもの

| 成果物 | 元ファイル | レビューHTML |
|--------|-----------|-------------|
| CSW61会議設計 v3 | `会議設計/CSW61_architecture_v3.md` | `reviews/CSW61_architecture_v3/bundle/index.html` |

**プレビューURL（ローカル）:** http://127.0.0.1:64312/index.html

ブラウザで開き、気になる箇所を選択 → コメントを書いてください。

## 次にレビュー候補

- `会議設計/CSW61_final_agreement_draft.md`
- `会議設計/CSW61_BG_architecture.md`
- `docs/` 配下の重複成果物（必要なら統合してから）

## 基本の流れ

```mermaid
flowchart LR
  A[Claudeがリサーチ/設計] --> B[Markdown成果物]
  B --> C[document-model.json へ変換]
  C --> D[HTML bundle 生成]
  D --> E[ブラウザでレビュー]
  E --> F[ingest-review でコメント取り込み]
  F --> G[Claudeが反映して再生成]
```

1. **生成** — Claude が `会議設計/` などに Markdown を書く
2. **変換** — `reviews/scripts/md_to_document_model.py` でレビュー用モデルへ
3. **レンダリング** — workbench CLI で HTML bundle を作る
4. **レビュー** — プレビューを開いてインラインコメント
5. **取り込み** — `ingest-review` でコメントを JSON 化
6. **改善** — Claude に「コメントを反映して」と依頼 → 再レンダリング

## コマンド（コピペ用）

```bash
# 環境
export PY=/opt/homebrew/bin/python3.12
export ROOT="/Users/onoshusei/Desktop/課外活動/模擬国連/日吉前期"
export WB="$ROOT/.tools/reviewable-html-workbench"

# 例: CSW61_architecture_v3 を再ビルド
NAME=CSW61_architecture_v3
SRC="$ROOT/会議設計/CSW61_architecture_v3.md"
OUT="$ROOT/reviews/$NAME"

"$PY" "$ROOT/reviews/scripts/md_to_document_model.py" \
  --input "$SRC" \
  --output "$OUT/document-model.json" \
  --title "CSW61 模擬国連会議設計まとめ v3" \
  --document-id csw61-architecture-v3

cd "$WB"
"$PY" -m scripts.html_review_workbench.cli check-model --model "$OUT/document-model.json"
"$PY" -m scripts.html_review_workbench.cli render --model "$OUT/document-model.json" --output "$OUT/bundle"
"$PY" -m scripts.html_review_workbench.cli validate --root "$OUT/bundle"
"$PY" -m scripts.html_review_workbench.cli preview --root "$OUT/bundle" --mode local
```

## レビュー後に Claude Code へ依頼する文言

```
reviews/CSW61_architecture_v3/bundle のレビューコメントを ingest-review して確認して。
actionable な指摘は 会議設計/CSW61_architecture_v3.md に反映し、
document-model を更新して HTML を再レンダリングして。
```

## Claude Code プラグイン

すでにインストール済み:

```bash
claude plugin install reviewable-html-workbench
```

日吉前期ディレクトリで Claude Code を開くとき:

```bash
cd "/Users/onoshusei/Desktop/課外活動/模擬国連/日吉前期"
claude
```

スキル `reviewable-design-doc` が使えます（「レビュー可能な設計資料をHTMLで」などで起動）。

## 注意

- `build-model` は下書き退避用。**そのまま render しない**
- 最終モデルは `reviews/scripts/md_to_document_model.py` か、Claude が直接 `document-model.json` を設計する
- Python は **3.12** を使用（`/opt/homebrew/bin/python3.12`）
- workbench 本体は `.tools/reviewable-html-workbench/`（git 管理外）
