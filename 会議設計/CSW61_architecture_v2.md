## 2. 模擬国連の設計方針

### 2.1 当初案の棄却：パレスチナを含む単一決議のコンセンサス採択

当初、論点①（経済×女性）・論点②（パレスチナ×女性）・論点③（先住民族×女性）を統合した単一決議のコンセンサス採択を設計目標として検討したが、以下の理由で棄却した。

- パレスチナ決議は史上一度も合意結論に統合されたことがなく、制度的に分離が前提
- イスラエル・米国が参加する模擬国連では必ずブロックされる
- 欧州は「棄権」という逃げ場を失い、コンセンサス形成が原理的に不可能になる

確かにこれらを統合することは対話の深化というコンセプトには合理的な一方、現実との乖離が大きくなりすぎることによる（ただでさえ少ない）リサーチ資料の直接的な有用性が減退する。同時に、合意可能性を感じさせなさすぎることによる「シラけ」、または合意のハードルが高すぎることによる失敗可能性が高い。

### 2.2 採用する設計方針

**論点①（経済×女性）と論点③（先住民族×女性）を統合した合意結論のコンセンサス採択**を会議のゴールとする。論点②（パレスチナ）は議題から除外する。

この設計で残る争点（not論点）は史実のCSW61で実際に難航した以下の5点であり、十分な交渉密度を持つ：

| 争点                    | 対立軸           |
| --------------------- | ------------- |
| A：SRHR「権利」表現          | 革新派 vs OIC保守派 |
| B：開発の権利・ODA義務         | G77 vs 先進国    |
| C：先住民族の権利宣言の援用強度      | 革新派 vs 米国・カナダ |
| D：「政策空間」文言の実質条項への波及   | 保守派 vs 革新派    |
| E：CEDAW留保の「撤回」vs「見直し」 | 革新派 vs 包括留保国  |

### 2.3 会議コンセプトとの整合性

再説：会議コンセプト
> 対話の深化

→当会議における具体的な実装 
> **「CSW59の失敗を参加者自身が対話で乗り越える体験」**

単なる文言のバーター交渉ではなく、以下の3点を会議設計の核心に置く：

1. **各陣営の理念的止揚**：単に「内政不干渉だからムリ」というワンパターンの攻防を超え、各ブロックおよび各国内でスタンスの矛盾を露呈させた状態でモデを終え、アンモデ以降の柔軟な交渉可能性を担保し、理念的な対話[^1]の土壌を揃える
2. **CSW59の失敗の克服体験**：「人権」という抽象語の正面衝突ではなく、既存文書の文言を援用した迂回表現の探索という**法的創造性（要検証）の競争・協働**として設計する
3. **高いハードルのコンセンサス採択**：全員が「不満だが受け入れられる」ギリギリの文言に着地することを明るい目標として設定しつつ、到達が容易ではない構造にする

注：結局のところ合意ハードルを意図的に高く設定することによる難易度調整なので、会議に至るまでの間のデリのモチベーション管理、しかも数人のデリではなく会議全体のモチベ管理が会議準備中の課題になりそう。

## 3. アンモデにおける交渉ダイナミクスの設計：4局面と3つの転換点



### 3.1 4局面の構成

```
局面①：序盤（前文交渉）
  ↓ 転換点①：保守ブロック内部分裂の誘発
局面②：中盤（実質条項・3つの同時進行する攻防）
  ↓ 転換点②：先住民族論点で保守派の論理が自己矛盾する
局面③：後半（SRHR迂回表現の発明）
  ↓ 転換点③：CSW59方式（正面衝突）からCSW61方式（迂回）への転換
局面④：終盤（政策空間条項をめぐる最終攻防→コンセンサス採択）
```

---

### 3.2 局面① 序盤[^2]：前文交渉

**最初の攻防点：PP5（ICPD「再確認」か「想起」か）**

革新派がカイロ行動計画（ICPD）を「再確認（reaffirm）」する文言を要求。サウジ・バチカンが「想起（recall）」へのダウングレードを要求。この一語の差がSRHR攻防の伏線となるため、革新派の最初の「死守ライン」として機能する。

**PP6「政策空間」の前文への挿入**

ロシア・中国が「各国の政策空間とリーダーシップを尊重」という文言の挿入を要求。革新派はこれが後の実質条項の抜け穴になることを察知し抵抗するが、「前文に限定する」という条件で受け入れる方向へ。

**PP7のパッケージ交渉**

「普遍的・不可分・相互依存」（革新派の要求）と「開発の権利を含む」（G77の要求）を同一段落に共存させるパッケージ交渉が発生。双方が片方ずつ不満を抱えながら受け入れる構造。

---

### 3.3 転換点①：保守ブロック内部分裂の誘発

**設計上の仕掛け：G77資金要求を先行させる**

実質条項のB（開発の権利・ODA）の交渉を先行させることで、OIC保守国（サウジ・インドネシア）がG77として先進国に資金要求を突きつける側に回る局面を作る。

**露呈する矛盾：**
「内政不干渉」を盾に人権表現を拒否していた国が、今度は「先進国よ、我々の開発に介入せよ（資金を出せ）」と要求する。革新派（北欧・EU）がこの非対称性を突く：

> 「あなた方は開発には外部コミットメントを求め、人権には内政不干渉を主張する。この非対称性をどう正当化するか？」[^3][^4]

これが「内政不干渉一辺倒」というワンパターンを破る最初の亀裂となる。

**期待される対話の展開：**
- サウジ：「開発の権利は既確立の国際法原則（1986年宣言）。人権の普遍性は西洋的価値の押しつけ」と論理を精緻化しようとする
- 革新派：「開発の権利宣言も人権宣言も同じ国連総会決議。選択的援用は許されない」と返す
- 中国：「開発の権利こそが最も基本的な人権」という独自フレームを提示

やや子供騙し的な側面があることは否めないとしても、開発の権利 v.s. 女性の権利 の優越関係　
→普通にデッドロックであることは確か、対話への道ぃ...

---

### 3.4 局面② 中盤：3つの同時進行する攻防

**攻防A：CEDAW留保（(a)条項）**

```
革新派：「留保を撤回する（withdraw）」
　　↕
サウジ・インドネシア：「留保は主権的権利。撤回要求は内政干渉」
　　↕
最終調停候補：「撤回することを検討し見直す（review with a view to withdrawing）」
```

**攻防B：ODA・技術移転（(ll)(ee)条項）**

```
G77（南アフリカ・インド）：「ODA義務を履行する（fulfill the obligation）」
　　↕
EU・北欧：「促す（urge）にとどめる。義務化は拒否」
　　↕
米国（トランプ政権）：「0.7%目標の文言自体を削除」を要求
　　↕
G77の結束強化：米国の削除要求がG77を結束させてODA義務論をエスカレートさせる（バックファイア）
　　↕
最終調停候補：「促す（urge）」＋0.7%目標値は残存
```

**攻防C：先住民族の権利宣言（(gg)条項）**

```
革新派・ブラジル：先住民族の権利宣言を「再確認する（reaffirm）」
　　↕
米国・カナダ：宣言への反対・棄権国として「重要性に留意する（noting the importance of）」へのダウングレードを要求
　　↕
サウジ・インドネシア：「伝統的・先祖代々の文化慣行を尊重する」という文言の挿入を試みる
```

---

### 3.5 転換点②：先住民族論点で保守派の論理が自己矛盾する

**設計上の仕掛け：「文化的固有性の尊重」の逆用**

「文化慣行を尊重する」という保守派が挿入しようとした表現を、革新派が逆用する：

> 「インドネシアやインドは国内に先住民族・少数民族を抱えている。『先住民族女性の伝統的慣行を尊重せよ』という表現は、自国の少数民族コミュニティへの外部批判を封じる根拠にもなるが、同時に自国の少数民族女性への差別的慣行を温存することも意味しないか？」[^5]

**保守ブロックの分裂：**
- サウジ：先住民族問題と無縁なので「文化慣行の尊重」に賛成できる
- インドネシア・インド：自国の少数民族政策への批判に転化しうるため留保が必要になる

これで「保守 vs 革新」という二項対立が崩れ、保守ブロック内部の利害分裂が可視化される。

---

### 3.6 局面③ 後半：SRHR迂回表現の発明（クライマックス）

**CSW59の失敗パターン（再現してはいけない）：**
「人権」表現をめぐる抽象的正面衝突 → 保守ブロックの全面削除要求 → 着地点を失って政治宣言に格下げ

**CSW61方式（参加者に発見させる）：**
「SRHR」という一語を回避しつつ、カイロ行動計画（PP5で「再確認」済み）の文言を援用することで実質を確保する迂回表現の発明。

```
革新派の要求：「性と生殖の健康と権利（SRHR）」の一語明記
　　↕
保守派の要求：「権利」を「健康」に変えよ
　　↕
北欧が提案する迂回表現：
「国際人口開発会議行動計画および北京行動綱領に従い、
 女性の人権には、強制・差別・暴力なしに性的・生殖的健康を含む
 事項を自ら制御・決定する権利が含まれることを認識する」
```

**保守派が受け入れ可能な論理：**
カイロ行動計画はPP5で「再確認」されている。その内容の反復に過ぎないという論理で拒否しにくい。

**革新派が不満を抱えつつ受け入れる論理：**
「制御・決定する権利」という実質的な権利表現が残っている。

**これがCSW59克服の瞬間：**
抽象語（「人権」「SRHR」）の正面衝突ではなく、すでに合意済みの過去文書の文言を積み重ねることで実質を確保する——これがCSW交渉の本質的な技術であることを参加者が体感する。

---

### 3.7 局面④ 終盤：政策空間条項をめぐる最終攻防

**設計上の「最終爆弾」：**

ロシア・中国が実質条項の末尾に以下の条項の挿入を要求：

> 「上記の行動要請の実施は、国内法および各国の優先事項、ならびに異なる国家・地域の慣行・アプローチを十分に考慮しながら行われるものとする」

**革新派の反論：**
「前文PP6にすでに政策空間への言及がある。実質条項への挿入はすべての行動要請を事実上無効化する白紙委任条項だ」

**議長（ブラジル）の調停：**
「PP6への政策空間言及で十分。実質条項への挿入は受け入れられない。ただし各条項の冒頭に『適切な場合には（where appropriate）』という限定句を追加することで、各国の状況への配慮を示す」

**コンセンサス採択への着地：**
この調停案を全員が「不満だが受け入れられる」水準として受諾し、コンセンサス採択に至る。

| 実質条項A | (a)(b)(c) | CEDAW留保の「撤回」vs「見直し」 |
| 実質条項B | (d)(e)(f) | 経済的権利（比較的合意しやすい） |

## 6. CSW59失敗の克服という会議コンセプトの具体的実装

### 6.1 CSW59が失敗した構造

| 失敗要因 | 内容 |
|---------|------|
| 正面衝突 | 「人権」表現をめぐる抽象的対立が解消されず |
| 密室化 | 会期前の非公開協議で実質決定→市民社会が排除された |
| 格下げ | 合意結論ではなく政治宣言という成果形式の後退 |

### 6.2 模擬国連での克服体験の設計

| CSW59の失敗 | 模擬国連での克服設計 |
|------------|-------------------|
| 抽象語の正面衝突 | 既存文書援用による迂回表現の発明（転換点③） |
| 二項対立の固定化 | 保守ブロック内部分裂の誘発（転換点①②） |
| 密室化・市民社会排除 | NGO/市民社会代表を会議に参加させ、交渉の透明性を確保する運営設計 |
| 成果形式の格下げ | 「政策空間条項の削除」という最終攻防を経てコンセンサス採択に至る（局面④） |

### 6.3 参加者に体感させるべき3つのこと

**① 文言は政治である**
「再確認（reaffirm）」と「留意（note）」の違い、「権利（rights）」と「健康（health）」の違い——一語の差に各国の利害と長期的な規範形成戦略が凝縮されている。

**② ソフトローは「積み重ね」で意味を持つ**
合意結論は法的義務を生まないが、「前回の合意結論を再確認する」という文言の積み重ねがopinio jurisを形成し、将来のハードロー化への布石となる。保守側がこれを阻止しようとするのはそのためである。

**③ ロジックの応酬は「武器の交換」ではなく「矛盾の発見」で動く**
「内政不干渉だからムリ」というワンパターンは、その国自身の他の主張との矛盾を突かれたとき初めて動く。国際交渉の本質は相手の論理を否定することではなく、相手の論理の内部矛盾を相手自身に気づかせることにある。
